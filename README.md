# Matsui-dotfiles

Esse projeto foi criado para compartilhar o meu rice e minhas configurações que eu uso no meu linux, desde já venho dizer que não tenho muita experiência em git hub, portanto, peço perdão se esse documento estiver bastante desorganizado, ainda estou aprendendo a mexer nessa plataforma. Enfim... Abaixo, estarei especificando e apresentando alguns pontos antes de vocês utilizarem as dotfiles.

Plataforma: Arch Linux, Hyprland.

# Apps necessários:
Alguns aplicativos extremamente necessários para a dotfile funcionar.

- Waybar (Barra);
- Rofi(Navegador de Aplicativos + Interface de Energia);
- Yazi (Explorador de Arquivos);
- Hyprpaper (Wallpaper);
- Hyprlock (Bloqueador de tela);
- Kitty (Terminal);
- NeoVim (Editor de código);
- Hyprland (Interface gráfica)
- Starship (Plugin do zshell)
- Grim (Print)

# Como utilizar?

É necessário primeiro que você tenha todos esses aplicativos listados acima instalados, então, os arquivos que estão no git hub
